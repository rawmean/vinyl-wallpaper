Frequently Asked Questions

Why isn't Vinyl Wallpaper showing my track?

Make sure your audio source is correctly selected. For Spotify, the Spotify desktop app must be running. For WiiM, your device must be on the same Wi-Fi network and reachable. For Apple Music and AirPlay, you may need to grant Vinyl Wallpaper Automation permission in System Settings → Privacy & Security → Automation.

The artwork doesn't match the album I'm listening to.

Vinyl Wallpaper fetches artwork from the iTunes Search API and Spotify's oEmbed service. For tracks that appear on multiple albums — especially in classical music — the API may return the most common release's artwork. This is expected behaviour.

How do I grant the required permissions?

Vinyl Wallpaper needs a few macOS permissions to work:

  • Automation — Go to System Settings → Privacy & Security → Automation and enable Vinyl Wallpaper for Spotify and Music.
  • Audio Input — Required for the VU meter animation on the turntable wallpaper. Grant when prompted.
  • Local Network — Required to discover WiiM and AirPlay devices. Grant when prompted.
